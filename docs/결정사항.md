## 기술 구성 (1단계 추가)
| 항목 | 선택 | 라이선스 | 이유 |
|---|---|---|---|
| HWP·HWPX 읽기 | kordoc 4.25.3 (확정) | MIT | HWP 5.x를 메모리 안에서 HWPX로 바꿔 표·셀·글자 모양을 읽음. 원본 파일은 바꾸지 않음 |
| XML 읽기 | @xmldom/xmldom 0.9.12 | MIT | HWPX·DOCX 안의 XML을 읽음 |
| 압축 파일 읽기 | jszip 3.10.1 | MIT 또는 GPL-3.0 중 선택 → **MIT로 사용** | HWPX·DOCX는 ZIP 파일 |
| 시험용 HWP 만들기 | @rhwp/core 0.9.1 | MIT | 가상 양식을 HWP로 만들어 시험할 때만 씀. 제품 설치에는 들어가지 않음(개발용) |

- **선택 설치 꾸러미 제외:** kordoc은 OCR·그림 변환용 꾸러미(onnxruntime 566MB, sharp 등)를 기본으로 함께 설치한다. 양식 읽기에는 필요 없어서 `시작.bat`에서 `--omit=optional`로 뺐다. 설치 크기 768MB → 78MB, 표준 양식 13종 분석 결과는 똑같음을 확인. 이 때문에 LGPL 라이선스인 libvips(sharp)도 설치되지 않는다.

## 기술 구성 (2단계 추가)
| 항목 | 선택 | 라이선스 | 이유 |
|---|---|---|---|
| HWP 쓰기 | @rhwp/core 0.9.1 (제품 꾸러미로 옮김) | MIT | 셀 안 문단 지우기·나누기, 글자·문단 모양 바꾸기가 되고, 고치지 않은 부분을 원본과 똑같이 저장함(확인함). kordoc의 HWP 수정은 셀 안 문단 삭제가 안 됨(요구사항 4.3). Java가 필요한 hwplib은 기관 PC 설치 부담 때문에 쓰지 않음 |
| HWPX·DOCX 쓰기 | 직접 구현(XML 부분 교체) | — | 고치지 않는 글과 압축 안 파일을 바이트 그대로 두기 위해 |

- rhwp는 HWP 저장 때 자체 표시 스트림(RhwpLineSegTags, 40바이트)을 덧붙인다. 지우면 파일 구조를 직접 고쳐야 해서 그대로 둔다(2단계 보고 6장).
