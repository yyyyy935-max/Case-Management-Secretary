# 결정사항

요구사항 11장 "사용자가 정할 것"에서 확정된 내용을 기록한다.

| 항목 | 결정 | 날짜 | 비고 |
|---|---|---|---|
| 설치 형태 | ① 기관 PC에서 실행하는 로컬 프로그램 | 2026-11-23 | 127.0.0.1에서만 접속되는 서버 + Chrome/Edge 화면 |
| AI 제공자 | Gemini | 2026-11-23 | **결제(유료 등급)가 연결된 API 키만 사용.** 무료 등급은 입력 데이터가 Google 제품 개선에 쓰일 수 있어 7장 조건에 맞지 않음. 모델 이름은 3단계에서 정함 |
| 체크 기호 기본값 | ☑ | 2026-11-23 | 요구사항 4.1의 기본값(■)을 이 결정으로 바꿈. 설정에서 ■, V로 바꿀 수 있음 |
| 시범 지역 | 미정 | | 6단계 전에 정함 |
| 공공데이터포털 API 키 | 미발급 | | 6단계 전에 사용자가 발급 |
