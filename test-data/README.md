# test-data (시험 자료)

이 폴더의 파일은 **GitHub에 올라가지 않습니다.** 이 README와 빈 폴더 표시 파일만 올라갑니다.

| 폴더 | 넣을 것 |
|---|---|
| `forms/` | 시험할 양식 파일 (서울시 사회복지관 표준 양식 13종 등). **빈 양식만** 넣습니다. HWP는 HWP, HWPX는 HWPX 그대로 넣습니다. |
| `cases/` | 가상 사례 (요구사항 9.1). 실제 사례를 각색한 내용은 넣지 않습니다. |

## 지켜야 할 것
- 실제 대상자의 개인정보가 들어 있는 파일은 넣지 않습니다(절대 규칙 5).
- 서울시 표준 양식은 협회 저작물이므로 시험에만 쓰고 제품에 넣지 않습니다(절대 규칙 6).
- 파일 이름은 바꾸지 않아도 됩니다. 양식 종류는 프로그램이 파일 내용을 읽어 구분합니다.
