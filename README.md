# 사례비서

사례관리 담당자가 상담 기록을 쌓아 두면, 기관 양식 파일(HWP·HWPX·DOCX)의 채울 수 있는 칸을 원본 서식 그대로 채워 주는 업무 도우미입니다.
기관 PC에서 실행하는 프로그램이며, 사례 기록과 채운 서류는 이 PC에만 저장됩니다.

- 요구사항: [docs/요구사항.md](docs/요구사항.md)
- 확정된 결정: [docs/결정사항.md](docs/결정사항.md)
- 현재 진행: **3단계 (사례 카드와 기록 쌓기, AI 사실 뽑기)** — [docs/3단계-보고.md](docs/3단계-보고.md) · 이전: [2단계](docs/2단계-보고.md), [1단계](docs/1단계-보고.md)
- AI 작성 지침 초안: [docs/AI작성지침_초안.md](docs/AI작성지침_초안.md)

## 실행 방법 (Windows)

### 1. Node.js 설치 (처음 한 번만)
1. https://nodejs.org 에 들어갑니다.
2. **LTS** 라고 적힌 버튼을 눌러 설치 파일을 내려받습니다.
3. 설치 파일을 실행하고 계속 [Next]를 눌러 설치를 마칩니다. 옵션은 바꾸지 않아도 됩니다.

### 2. 사례비서 내려받기
1. GitHub 저장소 화면에서 브랜치를 `claude/tender-sagan-brme53`로 고릅니다.
2. 초록색 **[Code]** 버튼 → **Download ZIP** 을 누릅니다.
3. 내려받은 ZIP 파일을 마우스 오른쪽 버튼 → **압축 풀기** 로 원하는 폴더(예: `문서\사례비서`)에 풉니다.
   - **ZIP 파일을 더블클릭해서 그 안의 `시작.bat`을 바로 실행하면 안 됩니다.** 반드시 압축을 푼 폴더에서 실행합니다.

### 3. 실행
1. 압축을 푼 폴더에서 **`시작.bat`** 을 더블클릭합니다.
   - "Windows의 PC 보호" 창이 나오면 **추가 정보 → 실행** 을 누릅니다.
2. 처음 실행할 때는 필요한 파일을 내려받느라 몇 분 걸립니다(인터넷 필요).
3. 브라우저에 **사례비서** 화면이 열리고 표에 "실행 중"이 보이면 성공입니다.
   - 화면이 자동으로 열리지 않으면 Chrome 또는 Edge 주소창에 `http://localhost:4870` 을 입력합니다.
4. 끝낼 때는 검은 창을 닫습니다.

> 사례비서는 이 PC 안에서만 접속됩니다. 같은 사무실의 다른 PC에서는 접속할 수 없습니다.

### 문제가 생겼을 때
| 증상 | 해결 |
|---|---|
| "Node.js가 설치되어 있지 않습니다" | 1번을 다시 하고, PC를 다시 시작한 뒤 실행합니다. |
| "필요한 파일이 이 폴더에 없습니다" 또는 `Temp\...\package.json` 오류 | ZIP 안에서 바로 실행한 경우입니다. 압축을 푼 뒤 그 폴더에서 실행합니다. |
| "내려받기에 실패했습니다" | 인터넷 연결이나 기관 방화벽을 확인합니다. |
| "4870번 포트를 이미 쓰고 있습니다" | 사례비서 검은 창이 이미 켜져 있는지 확인합니다. 다른 프로그램이 쓰고 있으면 `config.local.json`의 `port` 값을 다른 숫자(예: 4871)로 바꿉니다. |

## 사례 카드 쓰는 법 (3단계)
> **가상 사례만 넣으세요.** 이름·연락처를 가리고 AI로 보내는 기능은 5단계에서 만듭니다.

1. 화면 위쪽 **사례 카드**를 누르고, 왼쪽에서 **새 사례**를 만듭니다(가명).
2. **새 기록 넣기**에 상담·방문·전화 메모를 붙여 넣고 **저장**합니다.
3. AI 키가 있으면 **저장하고 사실 뽑기**를 누릅니다. AI가 찾은 사실이 **확인할 후보**로 나옵니다. 후보마다 근거 문장(기록 원문)과 말한 사람이 함께 나옵니다.
4. 후보를 **승인**(필요하면 고쳐서), 또는 **거절**합니다. 승인한 것만 사례 카드에 들어갑니다.
5. 근거가 기록에 없거나 담당자 의견인 후보는 자동으로 빠지고, **걸러진 후보**에서 이유를 볼 수 있습니다.

## 양식 칸 지도 쓰는 법
1. 사례비서를 실행하고 화면 위쪽의 **양식 칸 지도**를 누릅니다.
2. **파일 선택**을 눌러 양식 파일(HWP, HWPX, DOCX)을 고릅니다.
3. 왼쪽에 양식 표가 역할별 색으로, 오른쪽에 칸 목록이 나옵니다.
   - 위쪽 **양식** 목록에서 한 파일 안의 여러 양식(예: [양식3] 인테이크 기록지)을 고를 수 있습니다.
   - 오른쪽 위 단추(항목명, 입력칸, 판단 칸 등)를 누르면 그 역할의 칸만 보여 줍니다.
   - 왼쪽 칸이나 오른쪽 목록을 누르면 서로 위치를 찾아 표시합니다.
4. 역할이 틀린 칸은 오른쪽 목록의 선택 상자에서 바꿉니다. **확인 필요** 단추를 누르면 근거가 약한 칸만 모아 봅니다.
5. **고친 역할 저장**을 누르면 그 양식의 템플릿으로 저장됩니다. 같은 빈 양식을 다시 올리면 고친 역할이 그대로 쓰입니다. 템플릿은 이 PC의 `data/templates/`에만 저장됩니다.
6. **값 넣기:** 오른쪽 목록에서 칸을 누르면 값을 넣는 상자가 나옵니다. 체크 칸은 선택지에 체크하고, 글 칸은 글을 씁니다. 빈자리가 인쇄된 칸("(   회차)" 등)은 인쇄된 글이 미리 들어가 있으니 빈자리만 고치세요.
7. **채운 파일 만들기**를 누르면 원본과 같은 형식의 파일(`원래이름_채움.hwp` 등)을 내려받습니다. 자동 검사 결과, 확인할 점(좁은 칸 등), 채운 쪽의 원본·결과 그림이 함께 나옵니다.
8. 원본 양식 파일은 바꾸지 않습니다. 올린 파일과 만든 파일은 이 PC 안에서만 처리되고 사례비서가 따로 저장하지 않습니다.

## 설정 파일 (`config.local.json`)
처음 실행하면 `config.example.json`을 복사해 `config.local.json`이 만들어집니다. 메모장으로 열어 고칩니다.

| 항목 | 뜻 | 기본값 |
|---|---|---|
| `port` | 화면 주소의 번호 | 4870 |
| `checkMark` | 체크박스에 표시할 기호 (`■`, `☑`, `V` 중 하나) | ☑ |
| `ai.apiKey` | Gemini API 키. **결제가 연결된 유료 등급 키**만 쓰세요(무료 등급은 보낸 글이 학습에 쓰일 수 있음) | 비어 있음 |
| `ai.model` | Gemini 모델 이름. 비워 두면 쓸 수 있는 flash 모델을 자동으로 고름 | 비어 있음 |
| `publicDataApiKey` | 공공데이터포털 API 키 (6단계부터 필요) | 비어 있음 |

`config.local.json`에는 API 키가 들어가므로 다른 사람에게 보내거나 GitHub에 올리지 않습니다(자동으로 올라가지 않게 설정되어 있음).

## 폴더 구성
| 폴더 | 내용 |
|---|---|
| `src/server/` | 프로그램 본체 (이 PC 안에서만 도는 서버) |
| `src/forms/` | 양식 읽기(HWP·HWPX·DOCX)와 칸 역할 분류 |
| `src/cases/` | 사례 카드·기록 저장, AI 사실 뽑기와 걸러내기 |
| `src/ai/` | AI 호출(Gemini). 제공자를 바꿀 때 이 폴더만 고침 |
| `src/forms/fill/` | 원본 형식 그대로 채우기(HWP는 rhwp, HWPX·DOCX는 XML 부분 교체)와 9.2 자동 검사 |
| `scripts/` | 칸 분류 결과 표 만들기 |
| `public/` | 브라우저 화면 |
| `data/` | 사례 기록 저장 위치 (GitHub에 올라가지 않음) |
| `test-data/` | 시험용 양식·가상 사례 (GitHub에 올라가지 않음). [test-data/README.md](test-data/README.md) 참고 |
| `tests/` | 자동 검사. `tests/fixtures/`에는 시험용 가상 양식을 만드는 코드가 있음 |
| `docs/` | 요구사항, 결정사항 |

## 개발자용
```bash
npm install
npm start        # 서버 실행
npm test         # 자동 검사 (test-data/forms에 표준 양식이 있으면 그것도 검사)
npm run typecheck
npm run analyze -- test-data/forms/양식.hwp   # 칸 분류 결과를 test-data/reports/에 표로 저장
npm run eval:extract            # 가상 사례 10개로 AI 사실 뽑기 평가 (Gemini 키 필요, --fake는 키 없이)
```
